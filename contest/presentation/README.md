## 발표 순서

| 장 | 구간 | 내용 |
|---|---|---|
| 1~2 | 표지 · 목차 | 빌려 쓰는 노트북의 상태를 출고·수령·반납 세 시점에 기록합니다 |
| 3~6 | 왜 만들었나 | 반납할 때 발견한 흠집은 언제 생겼나, 반납 8개월 뒤 수리비가 청구된 사례, 대여 담당자 다섯 분 설문, 세 시점을 하나의 기록으로 |
| 7~12 | 서비스 시연 | 부스 촬영과 흠집 후보, 관리자 검수, QR 수령 촬영, 렌탈 전후 진단 비교, 반납 리포트(3D), 해시 체인과 서명 검증 |
| 13 | 하드웨어 | 도면을 그리고 직접 만든 촬영 부스 |
| 14~17 | 흠집 탐지 모델 | 노트북 15대 1,179장 촬영과 라벨링, 사전학습 → 미세조정 → 부스·서버 배포, 기본 모델과 비교, 라벨을 고쳐 다시 학습한 결과 |
| 18 | 마무리 | 다음 목표와 팀 역할 |
