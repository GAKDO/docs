# 심사 기준 ↔ 시연 시나리오 ↔ 증거

시연 시나리오(11/2 기준)는 하나입니다. ① 출고: 부스 촬영 → Jetson 탐지 → 기록, ② 수령: 고객 QR → 로그인 → 폰 촬영 → 업로드 → "새 흠집 없음", ③ 반납: 부스 촬영 → 바로 앞 시점과 비교 → 새 흠집 → A~D 등급 → 봉인(해시 체인), ④ 3D 리포트(핀·시점 슬라이더) + 공개 검증 페이지(+ 배터리·SSD 상태).

## 항목별로 무엇을 보여 줄까

| 심사 항목 (1차/최종) | 우리가 말할 것 | 보여 줄 장면 | 근거 증거 |
|---|---|---|---|
| 명확성/창의성 (40/30) | 렌탈 분쟁의 핵심은 "그 흠집이 언제 생겼나"인데 지금은 사진 몇 장과 말로 다툼. TRACE는 출고·수령·반납 **세 시점을 같은 기준(9면 정합, 1 px = 0.25 mm)** 으로 기록하고, 외관과 내부 상태(배터리·SSD)를 함께 남기며, **해시 체인으로 사후 조작이 없음을 누구나 검증** | ③ 비교표에서 새 흠집만 강조, ④ 검증 페이지에서 "변조 없음" | S1 비교표, S2 검증 페이지, F1 아키텍처 |
| 난이도 (25/20) | 엣지 AI(Jetson TensorRT 탐지) + 집 PC GPU 검사 워커, 호모그래피 정합으로 시점 간 같은 좌표계, 이벤트 기반 MSA 6개 서버, Ed25519 서명 해시 체인, 3D 트윈 | ① 부스 촬영 화면, 구성도 한 장 | S4 부스 화면, F1·F2, M1 추론 시간, M2 정합 오차 |
| 활용방안·기대효과 (25/20) | 노트북·카메라·태블릿 렌탈, 중고 거래 검수, 사내 장비 대여. 분쟁 처리 시간·보증금 정산 근거 단축. 공개 검증 URL을 고객·제3자에게 그대로 건넴 | ② 고객이 폰으로 수령 확인, ④ 리포트 공유 | 시장 자료(출처 필요), S3 3D 리포트, M5 업로드 시간 |
| 완성도 (10/10) | 실제 렌탈 3건을 처음부터 끝까지 돌림, 테스트·CI | 시나리오 ①~④ 끊김 없는 녹화 | M3 mAP, M4 판정 정확도, CI 통과 화면 |
| 전달력 (최종 10) | 문제 → 해결 → 시연 → 숫자 → 확장 순서 | – | 대본 |
| 질의응답 (최종 10) | 아래 예상 질문 | – | – |

## 5분 영상 구성안 (4분 40초 목표)

| 구간 | 길이 | 내용 | 노리는 점수 |
|---|---|---|---|
| 0:00~0:30 | 30초 | 문제: 반납 때 "원래 있던 흠집" 분쟁, 지금 방식(사진·체크리스트)의 한계 | 창의성 |
| 0:30~1:00 | 30초 | 한 문장 해결책 + 세 시점 그림 | 창의성 |
| 1:00~3:00 | 2분 | 시연 ①→②→③→④ 실제 녹화(자막으로 단계 표시, 기다리는 시간은 자름) | 완성도·창의성 |
| 3:00~3:40 | 40초 | 구성도 한 장 + 기술 포인트 3개(엣지 탐지, 정합, 해시 체인) | 난이도 |
| 3:40~4:10 | 30초 | 수치표: 추론 시간, 정합 오차(mm), mAP, 판정 정확도 | 난이도·입증 |
| 4:10~4:40 | 30초 | 활용처·확장("학습만 시키면 어떤 물건이든": 세 곳만 바꾸면 됨, 중고 검수), 팀 역할 | 활용·기대효과 |

1차 심사는 영상과 설명서만 보므로, 첫 1분 안에 "무엇이 새로운가"가 끝나야 합니다.

## 예상 질문

| 질문 | 답의 근거 |
|---|---|
| 조명·각도가 달라도 같은 흠집으로 맞춰지나? | 부스 고정 조명·카메라, 폰은 가이드 촬영, 4점 호모그래피로 표준 면에 정합, 정합 오차 M2 |
| 탐지가 틀리면 고객이 억울하지 않나? | 판정 불가 면은 따로 표시, 규칙 버전(rule_version)을 기록, 관리자가 근거 사진과 함께 확인 |
| 해시 체인이 왜 필요한가? DB 기록이면 충분하지 않나? | 운영자도 사후에 못 고침, 공개 검증 페이지로 제3자가 확인 |
| 폰 사진과 부스 사진 품질 차이는? | 폰 촬영 해상도·가이드 조건(WE2), 같은 모델로 탐지 |
| 노트북 말고 다른 물건도 되나? | 봉인·등급·영수증은 물건과 무관, 노트북에 묶인 곳은 촬영 목록·모델·기종 정보 세 곳뿐. 새 물건 = 형태 값 추가 + 사진 수백 장 + 미세조정([확장 설계](../design/asset-extensibility.md)) |
| 실제로 쓸 수 있나? 비용은? | Jetson 부스 1대 부품비, 집 PC 1대로 처리량, 렌탈 업체 도입 시나리오 |
| 개인정보는? | 사진은 기기 외관만, 보관·삭제 기간, 공개 검증 페이지엔 개인정보 없음 |
