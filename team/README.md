# 팀 운영

팀원 모두 Claude로 각자 맡은 파트를 개발합니다. 서로의 진행을 같은 곳에서 보도록 이 폴더를 원본으로 둡니다.

| 문서 | 내용 | 누가 고치나 |
| --- | --- | --- |
| [conventions.md](conventions.md) | 코드 컨벤션 (공통, Java·Spring, React·TS, Python, Git·PR) | PR로 합의 |
| [board.md](board.md) | 기능 27개와 운영 할 일의 상태 = 남은 작업 | 각자 자기 행 |
| [standup/](standup/) | 날짜별 스탠드업: 어제 한 일, 오늘 할 일, 막힌 것, 다음에 할 일 | 각자 자기 칸 |
| 구현현황 시트 (Google 시트, 링크는 팀 단톡방) | 기능 109개의 작동 여부, 서버별·담당별 구현율 | 각자 자기 담당 행 |

## 하루 흐름

1. **세션을 열면** Claude가 `/trace-standup start`로 보드와 어제·오늘 기록을 읽고, 오늘 할 일을 정해 자기 칸에 적습니다.
2. **일하는 동안** 기능을 시작·리뷰·완료할 때 보드 상태를 바꿉니다. 계약 변경·팀 결정은 오늘 파일의 "공유"에 한 줄.
3. **세션을 끝내기 전** `/trace-standup end`로 한 일·남은 것·막힌 것·다음에 할 일을 적습니다.
4. **매일 아침 사람이** 오늘 파일을 훑고 막힌 것을 정리합니다(5분).

세션을 만들 때 작업할 레포와 함께 **GAKDO/docs를 같이 연결**하면 Claude가 바로 읽고 씁니다. 연결이 안 되면 Claude가 연결해 달라고 알립니다.

## 규칙

- 자기 칸·자기 행만 고칩니다. 다른 사람 글은 지우지 않습니다.
- 한 줄에 하나, 짧게. 비밀번호·토큰·개인정보는 쓰지 않습니다.
- 이 폴더는 PR 없이 `main`에 바로 올립니다(스탠드업은 자주 바뀌어서). 그래서 docs 레포에는 PR 필수 규칙을 걸지 않습니다.

## 구현현황 시트

- Google 시트 "TRACE 요구사항 구현현황"에 기능 109개의 작동 여부와 서버별·담당별 구현율이 있습니다. 링크는 팀 단톡방에 있습니다(이 레포는 공개라 적지 않습니다).
- 시트는 팀원 Google 계정에만 편집 권한이 있습니다. 실제로 동작을 확인한 기능만, 자기 담당(H열) 행만 체크합니다. 작업 상태의 원본은 계속 [board.md](board.md)입니다.
- **Claude가 체크하게 하려면** [claude.ai/customize/connectors](https://claude.ai/customize/connectors)에서 Google Drive와 Google Sheets를 연결하고(시트 초대를 받은 계정으로) 새 세션을 엽니다. 그러면 `/trace-standup start`가 구현율을 함께 알려 주고, `end`에서 끝낸 기능을 보여 주며 체크할지 묻습니다.
- 연결하지 않았으면 시트에서 직접 체크합니다.
